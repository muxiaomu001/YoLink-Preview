# 演示人物头像

`people-grid.png` 为 2026-09-15 使用内置 image_gen 生成的虚构人物头像图集，4×4 等分，无真实用户照片。由共享 Avatar 组件按格展示；不依赖第三方头像服务。

生成提示词摘要：photorealistic-natural；一张精确 4×4 等格人像图集；16 位不同的成年东亚虚构人物，男女交替、25–65 岁、发型与眼镜有差异；自然光、真实皮肤、日常穿着、居家或办公室等柔和背景；每格头肩居中、可圆形裁切；无文字、标志、边框或格间距。

完整提示词用于单张图集生成，未用 CLI/API fallback。展示裁切由 CSS 完成，原始 PNG 保留。官方顾问使用固定图格，客户以昵称稳定选择图格；该映射仅服务 demo，真实产品应使用用户或企业设置的头像。
